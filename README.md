# EnglishLearning
#### 介绍
一款英语学习应用（内置离线词典），目前支持安卓和Windows系统。

#### 主要功能
1. 单词查询：含义、变形、异体、音节、关联单词和结构（词根词缀），部分有示例、发音或含义讲解视频；
2. 短语查询：含义，部分有示例、视频讲解；
3. 生词本：将单词或短语设为生词，包括导入、导出功能；
4. 背单词：按考级词汇或生词本背单词；
5. 语法：列举了相关错误使用示例；
6. 语调：旋律、重音、节奏；
7. 音素：声母和韵母发音（特别是对像t这样的独特发音搭配了相关视频进行全面讲解）；
8. 发音：弱化、缩读、连接，以及相关技巧，错误示例；
9. 运用：在不同场合如何有效地沟通和应对。

#### 软件架构
.NET9 MAUI
